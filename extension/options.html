Melon Agent Bridge

Connects ChatGPT, Claude, Gemini and Mistral tabs to the local Melon hub. Nothing is sent anywhere except the hub you configure below, unless you enable local AI. Enabling local AI only downloads model files from Hugging Face; prompts stay in this browser.

This is a one-time acknowledgement. Melon can read and type into the chat tabs you bind, and a run can expose prompt text to those tabs until you stop it.

Each controlled tab shows a Melon badge with its own control id. The same id appears in the Melon canvas. Use the badge or Stop all to cancel a run.

The token is generated at .melon-token when you run node server/hub.mjs. Keep the hub bound to localhost.

Runs a small planner model locally with WebGPU. The picker includes Qwen and comparable models. Downloading a model requires access to Hugging Face; no prompt or page text is sent there. 


        

          The loaded model can plan a graph from the canvas Brief panel; the hub validates it
          before anything is applied. AI is optional. If WebGPU, the model download, or the model host fails, Melon continues
          with deterministic adapters. Models are pinned to a Hugging Face revision and cached by the
          browser. Unload frees memory; it does not delete the cache.
